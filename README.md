# Rift & Ruin

The Godot project lives in `Game/`. Open `Game/project.godot` in Godot 4.7 or Summer Engine 0.8.5+.

- `Game/` — game source, scenes, assets, and Summer multiplayer manifests.
- `Launcher/` — launcher architecture plan; the .NET launcher is not implemented yet.
- `Updates/` — development manifest and release-note schema; no downloadable build is published.

The current playable project is the Godot project in `Game/`; the launcher and update files are not consumed by it yet.
